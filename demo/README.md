## 🚀 Quick Start

### 1. Get Your API Key
First, you need an API key from NagarikAPI:
- Sign up at [https://nagarikapi.com](https://nagarikapi.com)
- Go to your company dashboard
- Generate a new API key

### 2. Try an Integration Example
Check the `integrations/` directory for examples in your preferred language:
- **Python**: See `integrations/python/`
- **JavaScript**: See `integrations/javascript/`
- **PHP**: See `integrations/php/`
- **cURL**: See `integrations/curl/`

### 3. Try the NID Scanner
Check the `nid-scanner/` directory for a real-time NID scanning demo:
- **Web**: Open `nid-scanner/web/index.html` in your browser
- **Mobile**: Check `nid-scanner/mobile/` for a Flutter example
