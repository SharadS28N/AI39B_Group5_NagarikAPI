Introduction

NagarikAPI is an enterprise-grade identity platform that allows you to automate KYC, prevent fraud, and maintain compliance with a single REST interface.

Quickstart

To begin using the NagarikAPI platform, you'll need an API secret key. Register for a company account and visit your dashboard to manage your credentials.

Note: We recommend using our official SDKs to handle authentication, retries, and document uploads automatically.

Installation

Install the official Python client using pip:

Terminal
pip install nagarikapi-python

Verify your first identity

Here is a complete example of initiating an OCR request using our Python client.

example.py
import nagarikapi

# Initialize the client
client = nagarikapi.Client(api_key="ng_sk_prod_123...")

# Process a citizenship card
result = client.ocr.process(
   image_path=" citizenship.jpg",
   type="NP_ID_CARD"
)

print(result.full_name)
